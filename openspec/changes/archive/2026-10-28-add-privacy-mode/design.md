# Design

## Context

Заголовок menubar собирается в ядре (`DayTracker.snapshot` → `DaySnapshot.title`), экран перерыва — там же (`DaySnapshot.BreakScreen`). Тексты уведомлений с суммами формируются в `AppModel.deliver`. Снимок строится из `engine.settings`, так что флаг в `Settings` виден ядру без новых параметров. Перерывы уже задерживаются, пока заняты микрофон или камера (`CallDetector`).

## Goals / Non-Goals

**Goals:**
- Маска считается в ядре и покрывается тестами; view только показывает готовые строки.
- Переключение мгновенное, с клавиатуры, без системных разрешений.

**Non-Goals:**
- Автоматическое распознавание демонстрации экрана.
- Скрытие сумм в выпадающем меню и в окне настроек.
- Новые правила для перерывов.

## Decisions

**Флаг в `Settings.hidesAmounts`, а не в отдельном файле.** Переживает перезапуск, читается ядром через `engine.settings`, пишется существующим `AppModel.apply`. Старые файлы — `decodeIfPresent ?? false`. Альтернатива — состояние только в памяти `AppModel`: после перезапуска во время демонстрации сумма мелькнула бы.

**Маска в `DayTracker.snapshot`.** Ветка по фазе даёт иконку, при `hidesAmounts` значение заменяется на `•••`, `isAlert = false`. `BreakScreen.earnings` становится `String?` и равен `nil` в режиме; `BreakView` не рисует строку при `nil`. Так оверлей и menubar берут одно решение из одного места.

**Без автоопределения шаринга.** У macOS нет публичного API «экран сейчас захватывают»; `NSWindow.sharingType = .none` не соблюдается захватом через ScreenCaptureKit на современных macOS. Эвристики по запущенным Zoom/Телемосту путают «запущен» и «показывает экран». Ручной режим предсказуем, а созвон, во время которого обычно и шарят экран, уже задерживает перерывы.

**Горячая клавиша через Carbon `RegisterEventHotKey`.** Работает без разрешения «Универсальный доступ», в отличие от `NSEvent.addGlobalMonitorForEvents`. Комбинация ⌃⌥⌘M фиксированная; если её уже заняла другая программа, регистрация не удастся — пишем в лог, кнопка в меню остаётся. Отдельный маленький класс `PrivacyHotKey` в `Services.swift`, вызывает `AppModel.toggleHidesAmounts()`.

**Кнопка в меню** — иконка `eye` / `eye.slash` рядом с шестерёнкой, с подсказкой «Скрыть суммы (⌃⌥⌘M)» / «Показать суммы (⌃⌥⌘M)».

**Уведомления.** В `AppModel.deliver` при `settings.hidesAmounts` у `.dayStarted` тело «Сегодня 13 600 ₽» заменяется на «Хорошего дня», у `.dayEnded` заголовок теряет « · сумма». Остальные события сумм не содержат.

## Risks / Trade-offs

- [Демонстрация без микрофона и камеры, например запись экрана] → перерыв может появиться поверх, но суммы на нём скрыты.
- [⌃⌥⌘M занят другой программой] → сообщение в лог, переключение кнопкой в меню.
- [Пользователь забыл выключить режим] → суммы есть в выпадающем меню, иконка `eye.slash` напоминает о режиме.

## Migration Plan

Миграция не нужна: новое поле читается с умолчанием. Откат — удалить поле; старые версии игнорируют лишний ключ.
