# Spec Delta

## REMOVED Requirements

### Requirement: Обед остаётся по часам графика
**Reason**: Обед больше не стоит в графике: его включает и выключает пользователь (`lunch`), поэтому сдвигать или обрезать по фактическому началу нечего.
**Migration**: Сохранённое время обеда становится временем напоминания об обеде (`work-schedule`); окно обеда по графику для подсказок задаётся в `lunch` и тоже не зависит от фактического начала.
