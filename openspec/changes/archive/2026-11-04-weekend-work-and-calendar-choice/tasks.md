## 2. Ядро: работа в выходной — модель и трекер

  - Старая запись без ключа → `nil`.
  - Сегменты 10:00–12:00 и открытый с 12:30, `now` 13:30 → отработано 3 ч, состояние «идёт».
- [x] 2.2 `DayTracker`: `startWeekendWork(pay:now:)` (только при статусе `.nonWorking(.holiday)` и без `weekendWork`), пауза, продолжить, `finishWeekend`, «Продолжить работу», `setWeekendPay`, `cancelWeekendWork`; фаза `DayPhase.weekend(state)`; поля записи (`rateRUB`, `normHours = 0`, `earnedRUB`, `overtimeSeconds`) пересчитываются на каждом действии и тике. Проверка: новый WeekendWorkTests, время — `at("2026-10-31 …")` (суббота), ставка 1 700.
  - Активность весь день без кнопки → фаза `.nonWorking`, заработок 0 (автостарта нет).
  - Старт в отпуск / в рабочий день → ничего не происходит.
  - ×2, 3 ч → 10 200; ×1, 3 ч → 5 100; переработка, 2 ч → заработок 0, `overtimeSeconds` 7 200.
  - Пауза 12:00–12:30, сейчас 13:30, старт 10:00 → 3 ч; на паузе отработанное не растёт.
  - «Закончить» 13:00, «Продолжить работу» 20:00, «Закончить» 21:00 → 4 ч.
  - Смена оплаты с переработки на ×2 после 3 ч → 10 200, переработка 0.
  - Отмена → `weekendWork == nil`, заработок и переработка 0.
  - Простой 40 мин без паузы не останавливает отсчёт.
- [x] 2.2a Обед в выходной: `startLunch`/`endLunch` трекера работают во время работы в выходной через `DayRecord.lunches`, лимит и автоокончание общие с рабочим днём; «Пауза» на обеде недоступна, «Закончить» на обеде закрывает обед; обед входит в отработанное время. Проверка: тесты в WeekendWorkTests.
  - ×2, старт 10:00, обед 12:00–12:30, сейчас 13:00 → 3 ч, 10 200.
  - Пауза 12:00–12:30 вместо обеда → 2 ч 30 мин.
  - Обед с 12:00 без «Вернулся» → в 13:00 фаза снова «идёт».
  - Взято 60 мин → кнопки «Обед» нет; на паузе и в выходной без сессии — тоже нет.
- [x] 2.3 Полночь и перезапуск: тик пишет `lastActivityAt = now − idle`, пока сегмент открыт; `finalize` закрывает открытый сегмент по последней активности (не раньше начала сегмента, нет активности → в момент начала) и пересчитывает поля; `restore` того же дня сохраняет сессию. Проверка: тесты в WeekendWorkTests.
  - Старт 10:00 ×2, последняя активность 15:00, без «Закончить» → после `restore` следующим днём 5 ч, 17 000.
  - Пауза с 13:00 до полуночи → 3 ч.
  - Обед с 14:00 не закончен до полуночи → обед 14:00–15:00, 5 ч.
  - `restore` того же дня в 12:00 → сессия с 10:00, оплата прежняя.
  - Восстановление пропущенных дней не создаёт записей для выходных.
- [x] 2.4 Итоги месяца: `expectedRUB` прибавляет заработок записей месяца с `weekendWork`; переработка и «подарено» берут её из записей без изменений. Проверка: тесты в TrackerTests.
  - Оклад 272 000, суббота ×2 на 10 200 → ожидаемый 282 200, заработок месяца включает 10 200.
  - Будни 1 ч переработки + суббота 2 ч «как переработка» при 1 700 → 3 ч, подарено 5 100; суббота ×2 → переработка 1 ч.
