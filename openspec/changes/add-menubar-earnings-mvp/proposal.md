# Proposal

## Why

Хочется видеть прямо в menubar macOS, сколько денег уже заработано за текущий рабочий день, — как постоянную мотивацию работать дальше. При этом оклад фиксированный: всё, что сверх 8 часов, — бесплатная работа, и приложение должно это явно сигнализировать, а не поощрять.

## What Changes

- Новое нативное macOS-приложение `MagerMotivate` (Swift 6 + SwiftUI `MenuBarExtra`, macOS 26), только для личного использования, без Dock-иконки.
- Расчёт заработка в реальном времени: несколько месячных окладов в разных валютах (сумма «на руки»), ставка = Σ окладов ÷ (рабочие дни месяца × 8 ч), деньги идут все 8 часов, включая обед.
- Фиксированный рабочий график из настроек (начало, конец, обед); время идёт независимо от сна мака и активности пользователя.
- Производственный календарь РФ (выходные, праздники, переносы, сокращённые предпраздничные дни), отпуска диапазонами и разовый «Сегодня не работаю».
- Конвертация по курсу ЦБ РФ, зафиксированному на день; выбор валюты отображения ₽/$/€.
- Учёт переработки: после конца графика — по активности пользователя с ручными кнопками «Ещё работаю» / «Закончил»; падение реальной ставки дня; ежечасное напоминание.
- Отображение: растущая сумма в menubar с состояниями (до работы, работа, обед, переработка, выходной); выпадающее меню с почасовой разбивкой, итогами месяца, статистикой переработки и целью.
- Накопительные цели (название, сумма, % отчислений, уже накоплено), несколько одновременно, с прогнозом даты достижения.
- Выплаты у каждого дохода (день и доля оклада: аванс, зарплата) и ближайшая выплата с суммой в меню.
- Уведомления: начало дня, конец дня, ежечасная переработка, достижение цели.
- Локальная история по дням (JSON в Application Support), окно настроек, автозапуск при входе.

Вне скоупа MVP: эквиваленты («N капучино»), почасовые уведомления о заработке, разные графики для разных доходов, рыночные курсы, подпись/нотаризация/дистрибуция, синхронизация между устройствами.

## Capabilities

### New Capabilities
- `earnings-calculation`: источники дохода, расчёт часовой ставки, накопление заработка за день и месяц, конвертация валют по курсу ЦБ.
- `work-schedule`: рабочий график, производственный календарь РФ, сокращённые дни, отпуска и отгулы, определение состояния текущего момента (до работы / работа / обед / после / выходной).
- `overtime-tracking`: определение и учёт переработки после конца графика, реальная ставка дня, месячная статистика «подаренного» времени.
- `menubar-display`: заголовок в menubar и содержимое выпадающего меню.
- `savings-goal`: накопительная цель, прогресс и прогноз даты.
- `work-notifications`: системные уведомления о начале/конце дня, переработке и цели.
- `app-settings`: окно настроек, хранение настроек и истории, автозапуск.

## Impact

- Новый Xcode/SwiftPM-проект в корне репозитория; ядро расчётов — отдельный модуль с unit-тестами.
- Внешние зависимости по сети: `isdayoff.ru` (производственный календарь), `cbr-xml-daily.ru` (курсы ЦБ). Работа без сети — на кэше и фолбэках.
- Системные API: `MenuBarExtra`, `UserNotifications`, `SMAppService` (автозапуск), `CGEventSource` / уведомления `NSWorkspace` (активность, сон, блокировка экрана).
- Сторонних Swift-пакетов не требуется.
