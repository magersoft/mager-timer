# MagerMotivate

Виджет в menubar macOS: показывает, сколько ты уже заработал за рабочий день, и честно говорит, когда дальше работаешь бесплатно.

- Несколько месячных окладов в ₽/$/€ (курс ЦБ РФ фиксируется на день), ставка = Σ окладов ÷ норма часов месяца по производственному календарю РФ.
- Фиксированный график (по умолчанию 09:00–17:00, обед 13:00–14:00 входит в день). Сокращённые предпраздничные дни, отпуска, «Сегодня не работаю».
- После конца графика — учёт переработки по активности (15 мин простоя закрывают день), кнопки «Ещё работаю» / «Закончил», падение реальной ставки, статистика «подарено» за месяц.
- Накопительная цель с прогнозом даты, уведомления о начале/конце дня, переработке и цели.

Требования, решения и план — в [`openspec/changes/add-menubar-earnings-mvp`](openspec/changes/add-menubar-earnings-mvp).

## Требования

macOS 26, Xcode 26 / Swift 6.2+.

## Команды

```bash
swift test                       # тесты ядра расчётов (MotivateCore)
./scripts/build-app.sh           # собрать build/MagerMotivate.app
./scripts/build-app.sh --install # собрать, положить в ~/Applications и запустить
```

При первом запуске macOS спросит разрешение на уведомления. Автозапуск при входе включается сам (отключается в «Настройки → Общее»).

## Попробовать день, не дожидаясь вечера

```bash
open -n build/MagerMotivate.app --args \
  --data-dir /tmp/motivate-demo \
  --fake-now 2026-10-27T16:55
```

- `--fake-now yyyy-MM-ddTHH:mm` — сдвигает часы приложения; дальше время идёт как обычно.
- `--data-dir путь` — отдельная папка данных, чтобы не трогать настоящую историю.

## Данные

`~/Library/Application Support/MagerMotivate/`:

- `settings.json` — настройки;
- `history/YYYY-MM.json` — записи по дням (заработок, ставка, курс, переработка);
- `calendar-YYYY.txt`, `fx-latest.json` — кэш производственного календаря (isdayoff.ru) и курсов (cbr-xml-daily.ru).

Других сетевых запросов нет.

## Устройство

- `Sources/MotivateCore` — чистая логика без UI: календарь, ставка, фазы дня, переработка, цель, снимок для меню, хранилище. Покрыта тестами (`Tests/MotivateCoreTests`).
- `Sources/MagerMotivate` — SwiftUI-приложение: `MenuBarExtra`, окно настроек, уведомления, мониторинг активности, автозапуск.
